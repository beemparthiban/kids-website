# Big Letter Typing

A simple static page for helping kids learn typing and practice A-Z letters.

## Run Locally

Open `index.html` in a browser.

## Install On iPad

1. Open the published website in Safari while online.
2. Tap **Share**.
3. Tap **Add to Home Screen**.
4. Open **Little Typer** from the Home Screen once while online so it can save the app for offline use.

## Publish With GitHub Pages

1. Create a new GitHub repository.
2. Upload all files from this project, including `index.html`, `styles.css`, `app.js`, `assets/`, `.nojekyll`, and `.gitignore`.
3. In the repository, open **Settings > Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select the `main` branch and `/root`, then save.

GitHub will publish the site after a short build.
